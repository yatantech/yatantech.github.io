# Yatan Tech site

Public pages for Yatan Tech's games, served by GitHub Pages at https://yatantech.github.io.

- `index.html`: studio home with one card per game
- `app-ads.txt`: authorised ad sellers for every game (must stay at the site root)
- `style.css`: shared look
- `fuel-line/`: Fuel Line's page, privacy policy and support page
- `privacy.html`, `support.html`: forward to the Fuel Line pages (older builds and store forms link here; keep them)

Adding a game: copy `fuel-line/` to a new folder, edit the text, and add a card on `index.html`.
Keep each privacy policy in step with what that game actually does.
