# Fuel Games site

Public pages for Fuel Line, served by GitHub Pages:

- `index.html` home page
- `privacy.html` privacy policy (linked from the store listings and the game's Pause menu)
- `support.html` support page and contact email
- `app-ads.txt` authorised ad sellers (must stay at the site root)

Keep the privacy policy in step with what the game actually does (see the game repo's docs/spec decisions D37, D39, D42).
